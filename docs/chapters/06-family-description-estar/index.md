# Family, Description and the Verb Estar

## Summary

Opening Entreculturas Unidad 3, students learn family vocabulary, adjective agreement (gender and number), and the verb *estar* for describing location and contrasting it with *ser*. Students finish able to describe family members physically and by personality, and to say where things and people are.
